# 50DaysOfLearning-AND-100DaysTryingToBecomeDataAnalyst
🌟 Day 1 of my Data Analyst learning journey! Python basics including variables, data types, operators, input/output, and mini projects.  Part of my 50-day plan to become a job-ready Data Analyst in the UK.
### Day 1: Python Basics

- Learned Python fundamentals and set up my development environment (Jupyter Notebook / VS Code).  
- Topics covered:  
  - Variables and data types (`int`, `float`, `str`, `bool`)  
  - Type casting (`int()`, `str()`, `float()`)  
  - Comments (`# single line`, `''' multi-line '''`)  
  - Print function and string formatting (`print()`, f-strings)  
  - Basic operators (`+`, `-`, `*`, `/`, `%`, `**`)  
  - Taking input from users (`input()`)  
- Mini project:  
  - Wrote a Fahrenheit to Celsius converter using user input.  
- Python file: `Day1_PythonBasics.ipynb`

  
### Day 2: Control Flow – if-else, loops, conditions

- Learned how to control program execution using conditional statements and loops.  
- Topics covered:  
  - if, elif, else statements  
  - Comparison and logical operators  
  - for and while loops  
  - Loop control: break, continue, pass  
- Mini exercises:  
  - Checked if a number is even/odd  
  - Found the largest of three numbers  
  - Printed a multiplication table  
  - Calculated the sum of first N numbers  
- Python file: `Day2_ControlFlow.ipynb`
